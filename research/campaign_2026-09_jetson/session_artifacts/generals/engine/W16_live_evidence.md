The live SDK returns a pandas Timestamp with nanoseconds, so the harness never exercises order_utils.py:191-201 or the UserWarning. Add a case with the real `_load_models` on an empty model dir plus the halt flag that asserts the startup and cycle-1 broker events are byte-identical to the flat case with 0 buys. (d) Combined mode: the stock loop's cleanup ran mid-churn (`Canceling 0/6 open order(s)` at 03:09:26) and correctly left the crypto stops alone. The harness only drives CryptoLoop, so run_bots combined startup is uncovered.
