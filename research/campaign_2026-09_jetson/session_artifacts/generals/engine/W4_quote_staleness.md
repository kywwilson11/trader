## OWNER ITEM (JUDGMENT; not recommending a threshold)
In this 10-minute window DOGE and XRP had a None rate of 0/20 (max age 124 s each), so their software stops were evaluated every cycle. That contrasts with G2's 23:42 CDT sighting of DOGE ages of 212–225 s. The exposed name this time was ETH/USD: 3/20 cycles (15%) had no `_manage_stops` evaluation (ages 187–227 s), including one 2-poll streak of about 60 s with no software stop/trail/HWM/TP evaluation (base_loop.py:1293-1295 `continue`). Every observed None was `stale`; there were no error, missing, degenerate or crossed samples. At 300 s or more, every name was 0% in this window. Alpaca's crypto quotes clearly go quiet for minutes on any name at night, and which name does it rotates, so a 10-minute window is a small sample (n=20 per name). A multi-hour run is needed before the owner picks a number.
